# SULI — Portfólio de Editor de Vídeo

Site de portfólio pessoal do **Suli**, editor de vídeo focado em conteúdo do universo gamer para YouTube. Página única, estática, com identidade visual em preto e branco inspirada em timeline de edição de vídeo.

🔗 **Canal:** [youtube.com/@suli4200](https://youtube.com/@suli4200)

## Sobre o projeto

O Suli foi idealizado e executado de forma independente para aprimorar técnicas de edição e produção de vídeos para a internet. Todo o fluxo — pesquisa de pauta, montagem de cenas de gameplay, sincronização de áudio e ritmo narrativo — foi estruturado para entregar vídeos atrativos e informativos para a comunidade gamer.

**Principais competências:**
- Curadoria & Roteiro — pesquisa de mercado, organização de informações, preparação do canal
- Edição & Pós-produção — cortes e montagem, elementos dinâmicos em tela, trilha & SFX

## Stack

- HTML + CSS + JavaScript puro, em um único arquivo (`index.html`), sem dependências externas de build
- Fontes: [Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue), [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) e [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono), via Google Fonts
- Imagem de perfil incorporada diretamente no HTML (base64), sem arquivos de imagem separados
